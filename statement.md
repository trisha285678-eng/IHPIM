# Project Statement

## Project Title
Integrated Hospital Patient Information Management System

## Problem Statement
In a hospital, patient information can be spread across different activities such as registration, doctor details, appointments, medical records and billing. For a beginner-level academic project, there is a need for a simple system that demonstrates how these related records can be organized and accessed from one application.

## Scope
The project covers basic local management of:
- Patient information
- Doctor information
- Appointments
- Medical records
- Billing information

The project uses a console interface and JSON files. It is limited to educational use and does not provide the security, privacy, networking, authentication or database infrastructure required by a real hospital.

## Target Users
- First-year students learning Python
- Faculty evaluating programming concepts
- Users demonstrating a basic hospital information workflow

## High-Level Features
1. Patient management
2. Doctor management
3. Appointment management
4. Medical record management
5. Billing management
6. Local data storage
7. Input validation and testing

## Academic Concepts Demonstrated
- Variables and data types
- Input/output
- Operators
- Type conversion
- Lists and dictionaries
- Sets/collections where applicable
- if-else and loops
- Functions
- Modules and packages
- File handling
- Exception handling
- Classes, constructors and methods
- Encapsulation/basic OOP
- Unit testing
